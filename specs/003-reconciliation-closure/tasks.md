Domain rules (binding):
- `checkStatementClosure`: group by `accountingDate`; day sum = signed sum; day balance = first non-null `dayBalanceCents` of the group; days sorted ascending; walk with `previous = null`: if day balance is null or `previous` is null -> push day to `unverifiedDays` and set `previous = day balance` (may be null); else push `{ movementCents: balance - previous, sumCents, differenceCents: movement - sum, closes: difference === 0 }` and set `previous = balance`. `divergences` = days not closing; `closes = divergences.length === 0`.
- `statementFinalBalance`: last accounting date of all lines; first line of that date with non-null `dayBalanceCents`; else null (no fallback).
- `invoiceNetCents`: `-sum(signedCents)` over lines whose `lineKind !== "invoice-payment"` (expense lines are negative, so purchases add and credits subtract).
- `checkInvoiceClosure`: `differenceCents = expectedCents - netCents`, `closes = differenceCents === 0`.
- `parseAmountInputToCents`: trim; blank -> null; strip a leading `R$` and spaces; if it contains `,`: remove `.` thousands separators and read `,` as decimal; else a single `.` followed by 1-2 digits is decimal, other dots are thousands; up to 2 decimals; leading `-` allowed; anything else -> null.
- `toBalanceStatus`: `!isAdmin` -> null; `!isSettled` -> `unsettled`; `postingDate > cutoffDate` -> `after-end`; else `in-balance`.
- `projectAccountBalance`: `total = baselineCents`; for each `entry` effect whose entry exists with non-null status: `next = alignable ? lineCents : signedCents`; `total += next - (status === "in-balance" ? signedCents : 0)`; for each `create` effect with `forAdmin`: `total += lineCents`. `paidAfterEnd` = entries with status `after-end` not referenced by any `entry` effect, in entries order, mapped `{ entryKey, name, date: postingDate, signedCents }`.
- `projectInvoiceTotal`: sum of `-signedCents` over entries with `period === invoicePeriod`, where an entry referenced by an `entry` effect and `alignable` uses `-lineCents`; plus `-lineCents` of every `create` effect (any person).
- `compareProjection`: `differenceCents = Math.abs(targetCents - projectedCents)`, `matches = differenceCents === 0`.
- `isPaidButUnreconciled`: false when `isSettled !== true`, `hasIdentity`, or `firstReconciledDate === null`; else `date >= firstReconciledDate`.
- `isInformationalLine(line)` (private in `reconciliations.ts`): `line.lineKind === "invoice-payment"`.
- Plan creation `origin`: `"invoiceCredit"` when `targetType === "card"` and `line.lineKind === "credit"`, else `"regular"`.
