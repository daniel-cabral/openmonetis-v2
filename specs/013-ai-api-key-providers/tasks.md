declaration. Run only the touched test files while iterating; lint/typecheck once at the end.
Vendors are NEVER called in tests: adapters receive an injected `fetch`.

**Conventions**: follow AGENTS.md (feature shape, no barrels, UI copy PT-BR, code English). Mirror
the existing CLI provider code paths (`apps/ai/src/providers/*.ts`, `apps/api/src/utils/ai-service.ts`,
`apps/api/src/services/ai-providers.service.ts`, `apps/web/src/features/ai-providers/`). Never
`drizzle-kit push`; generate a versioned migration. Lane B: database from the worktree `.env`; never
start dev servers on default ports (7201-7203 only). Keys MUST never be logged, returned, put in error
messages or written to disk outside the encrypted column.
