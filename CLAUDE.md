## Local environment (Windows)

`pnpm dev` fails on Windows (scripts use `VAR=x cmd`). Run the servers directly from bash:

- API: `cd apps/api && DOTENV_CONFIG_PATH=../../.env ./node_modules/.bin/tsx watch --import dotenv/config src/index.ts`
- Web: `cd apps/web && ./node_modules/.bin/vite dev --port 7002`

`.env` uses `OPENMONETIS_PROJECT_NAME=openmonetis-v2` to keep Docker isolated from the V1 fork.
`apps/web/src/routeTree.gen.ts` is regenerated by `vite dev`; do not commit incidental diffs.
