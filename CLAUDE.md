## Fork-only workflow

All work lands on this fork (`origin`, `daniel-cabral/openmonetis-v2`). Do not open PRs, issues or
branches against `upstream` (`felipegcoutinho/openmonetis-v2`): the maintainer does not accept
external PRs for now. `upstream` is read-only, used only to fetch and merge new releases.
Push with the `daniel-cabral` GitHub account (the active gh account may differ).

Spec-driven work in this fork follows `.specify/memory/constitution.md` (spec-kit, `/speckit-*`).
AGENTS.md wins over any skill or doc that contradicts it (e.g. never `drizzle-kit push`; always
versioned migrations).

## Local environment (Windows)

`pnpm dev` starts API, web and AI service (they load the root `.env` via `--env-file-if-exists`).
The root `test:*:integration` scripts still use `VAR=1 tsx ...` and fail in cmd; run them from bash.

`.env` uses `OPENMONETIS_PROJECT_NAME=openmonetis-v2` to keep Docker isolated from the V1 fork.
`apps/web/src/routeTree.gen.ts` is regenerated by `vite dev`; do not commit incidental diffs.
